# TreatmentLane link development plan

Last updated: 2026-10-24

## Goal

Earn relevant links that help people verify treatment information. Do not buy links, use bulk directory submissions, exchange links at scale, or ask for links to thin provider pages.

## Linkable assets now available

- Editorial standards: `/about/editorial-standards`
- Listing verification method: `/how-we-verify`
- Correction process: `/corrections`
- Provider listing and claim flow: `/providers/apply`
- Source-backed care, location, and guide pages

## Priority outreach groups

1. Providers with a complete or confirmed TreatmentLane profile. Ask them to link to their exact profile from a resources, press, or locations page.
2. State and local treatment associations. Offer a transparent state resource page only when it contains useful listings and official citations.
3. Community health and recovery coalitions. Suggest the most relevant care guide or state page, not the homepage by default.
4. Licensing and public-information teams. Ask for corrections and source guidance first. A link is only appropriate when TreatmentLane adds useful public context.
5. Universities, libraries, and public health resource lists. Pitch source-backed educational guides with clear editorial ownership and review dates.

## Qualification rules

- The referring site must be relevant to behavioral health, public health, recovery, insurance, education, or local care access.
- The page must be publicly indexable and maintained by a real organization.
- The suggested TreatmentLane destination must already meet the search-index quality threshold.
- The message must explain why the link helps that page's readers.
- One personalized follow-up maximum unless the organization replies.
- Record the target, contact source, destination page, status, result, and live-link URL.

## First campaign

Start with 25 providers from the 250-page Search Console priority cohort that have a strong source record, complete contact details, and an indexable profile. Verify every profile before outreach. Then contact 10 state or local associations whose resource pages match an existing TreatmentLane state or care page.

## Measurement

- New relevant referring domains
- Live links that remain after 30 and 90 days
- Search impressions and clicks for the linked destination
- Referral visits and provider corrections generated by the link
- Spam score and relevance of each new domain

Outreach messages are external communications. Prepare each message and target first, then obtain final approval before sending.
